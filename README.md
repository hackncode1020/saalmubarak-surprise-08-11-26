# Saal Mubarak - Forever With You (Gujarati New Year surprise)

A romantic, single-page surprise website for Gujarati New Year (Bestu Varas, 10 November). Plain HTML, CSS and JavaScript, canvas fireworks, SVG art, synthesized WebAudio music (starts only after a tap), local fonts.

- Countdown targets 10 Nov 2026, 00:00 in the visitor's own time zone; at zero (or if already past) it shows "Saal Mubarak!".
- The visitor types their own name; all personalised lines use only that name.

Open `index.html` through any static server.
